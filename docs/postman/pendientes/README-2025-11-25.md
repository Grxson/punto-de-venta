## 📋 Reglas de Trabajo

### ✅ Al implementar un endpoint pendiente:
1. **Marcar como completado** en este archivo cambiando `- [ ]` por `- [x]`
2. **Agregar fecha de implementación** en formato `YYYY-MM-DD`
3. **Actualizar** `frontend-web/src/config/api.config.ts` si es necesario
4. **Actualizar** la colección de Postman si el endpoint no está incluido

### 🆕 Al crear un endpoint nuevo en el backend:
1. **Agregar el endpoint** a `docs/postman/punto-de-venta.postman_collection.json`
2. **Agregar el endpoint** a esta lista si no se implementa inmediatamente en el frontend
3. **Documentar** el propósito y uso del endpoint
